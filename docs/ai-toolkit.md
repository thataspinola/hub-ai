# Recursos do editor

O hub-ai reúne o painel e o Web Code Reviewer para Angular, React, Next.js e Vue, além do perfil frontend legado. Usar Copilot Setup e Web Code Reviewer no consumidor. Recursos fonte: resources/frontend; ferramentas: tooling/web-code-reviewer; configuração instalada do painel: .github.

- [Uso da CLI](code-reviewer-cli.md)
- [Migração e divisão dos projetos](reviewer-migration.md)
- [Avaliação humana](reviewer-evaluation.md)
- [Backend Code Reviewer](https://github.com/thataspinola/backend-code-reviewer)

Não copiar o toolkit inteiro para cada aplicação. A CLI instala os recursos necessários e preserva código, CI, instruções e customizações. Não executa modelos nem exige GitLab/Jenkins.
