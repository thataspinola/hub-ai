# Validação local

Execute os scripts declarados no `package.json`. O hub-ai não possui mais toolkit de Code Reviewer embutido. O único ponto de integração com o reviewer externo é a documentação, a rota informativa e o check pessoal somente de leitura.

Sem ambiente corporativo e dependências instaladas, não afirmar aprovação de build, autenticação, CI/CD ou E2E.
