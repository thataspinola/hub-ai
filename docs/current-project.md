# Projeto atual

O hub-ai contém o painel administrativo Next.js/React, autenticação NextAuth/Keycloak, feature flags, formulários dinâmicos, recomendações e respectivas rotas, componentes, stores e testes. O Code Reviewer foi separado do painel: não há mais toolkit frontend/backend distribuído neste repositório.

Revisões usam o [agente pessoal independente](global-reviewer.md). Preservar integrações, contratos e configuração corporativa; validar mudanças com os scripts do `package.json`. Testes locais não comprovam integrações reais na VDI.
