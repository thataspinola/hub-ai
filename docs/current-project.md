# Projeto atual

O hub-ai contém o painel administrativo Next.js/React, autenticação NextAuth/Keycloak, feature flags, formulários dinâmicos, recomendações e respectivas rotas, componentes, stores e testes. Para revisão de código, o painel utiliza o agente pessoal independente Code Reviewer Plug and Play.

Revisões usam o [agente pessoal independente](global-reviewer.md). Preservar integrações, contratos e configuração corporativa; validar mudanças com os scripts do `package.json`. Testes locais não comprovam integrações reais na VDI.
