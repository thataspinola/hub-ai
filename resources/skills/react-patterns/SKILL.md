# Padrões React

Detectar React, bundler, roteador e runner existentes. Não assumir Next.js, SSR ou Server Components em React SPA. Respeitar Rules of Hooks e dependências de effects; não mutar props/estado. Controlar efeitos, cleanup, stale closures e estado derivado. Memoizar só quando estabilidade/custo justificar. Preservar state management e fetching existentes, não impor Zustand/React Query. Testar comportamento com ferramentas configuradas e rotas/formulários. Manter segredos e autorização no backend; variáveis embutidas no bundle não são secretas.
