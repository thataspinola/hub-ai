# Padrões Vue

Detectar Vue 2/3, bundler, router, store e runner. Preservar Options/Composition API conforme código existente. Respeitar reatividade de props/ref/reactive, computed e watchers; evitar perder reatividade ao desestruturar sem mecanismo adequado. Fazer cleanup dos efeitos/subscriptions conforme ciclo de vida e versão. Validar emits, v-model, slots e formulários no contrato do componente. Não impor Pinia a projeto com Vuex. Não tratar Nuxt como Vue SPA: se existir SSR/Nuxt, documentar fronteiras/configuração antes de adaptar. Usar Vue Test Utils/Vitest/Jest somente conforme configuração real.
