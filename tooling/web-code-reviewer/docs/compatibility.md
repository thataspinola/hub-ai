# Compatibilidade e limites

Ferramentas exigem Node 22+; testes locais usam Node 24/Linux. Instalação dos perfis Angular, React, Next.js, Vue e frontend legado é exercitada com pacotes sintéticos. Não certifica todas as versões desses frameworks nem execução no editor.

CLI/installer/doctor usam módulos nativos. YAML é dependência de desenvolvimento. Selecionar o framework/versão e runner reais do consumidor; TypeScript acompanha o perfil, não constitui um perfil separado. Windows/macOS e descoberta dos agentes no editor permanecem pendentes.
